The source in this repository is licensed under the **GNU Affero General Public

In practice this means you are free to use, study, modify and redistribute
OhNews, **including for commercial purposes**, at no cost, provided you meet the
AGPL's conditions:

- If you distribute the app or a modified version, you must pass on the same

- **Section 13**: if you run a modified version as a network service that users
  interact with remotely, you must offer those users the corresponding source.
- You must keep the copyright notices and the license text intact.

Apache-2.0 is compatible with the AGPL, so the bundled Mozilla Readability.js
can be shipped inside this AGPL work. See
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

## 2. Commercial license

Some organisations cannot accept the AGPL's copyleft obligations. A commercial
license is available for, among other cases:

- shipping OhNews inside a **closed-source product**;
- operating a modified version as a **hosted or managed service** without
  publishing your changes;
- internal policies that simply exclude AGPL software.

The commercial license removes the AGPL's source-disclosure requirements for the
licensed scope, and can include support terms.

**Contact:** open an issue or reach the maintainer through
<https://github.com/nipheryang> to discuss terms.

## 3. Which one applies to you

You do **not** need to choose up front. The AGPL applies to everyone by default;
a commercial license is an alternative for those who need it. If you are using
OhNews personally, in research, or in an open source project, the AGPL already
grants you everything you need and there is nothing to pay.

## 4. Contributions

Because the project is dual-licensed, the maintainer must hold sufficient rights
over all code in it to also offer it under the commercial license. Contributions
are therefore accepted only with a grant of those rights — see
[`CONTRIBUTING.md`](CONTRIBUTING.md) before opening a pull request.

## 5. A note on earlier versions

Releases published before 2026-09-12 were distributed under the terms stated at
that time. Licence changes are not retroactive: whatever terms accompanied a
release continue to apply to that release.
